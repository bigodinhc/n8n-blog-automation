## PARTE 4: TÉCNICAS AVANÇADAS DE OTIMIZAÇÃO

### 1. "Less is More" - Dynamic Tool Selection

```
PROBLEMA CLÁSSICO: Se você der 50 tools ao agent
├─ Confunde qual usar
├─ Escolhe errado 40% das vezes
├─ Performance cai drasticamente

SOLUÇÃO: "Less is More" (MIT Research 2024)
├─ Para CADA query, selecionar apenas tools relevantes
├─ Query: "Níquel drop analysis"
│  └─ Tools selecionadas: [NEWS, FUNDAMENTAL, MACRO, RISK]
│  └─ Tools NÃO oferecidas: [TECHNICAL, SENTIMENT, CRYPTO]
├─ Query: "Técnica setup para ouro"
│  └─ Tools selecionadas: [TECHNICAL, CORRELATION, SENTIMENT]
│  └─ Tools NÃO oferecidas: [NEWS, FUNDAMENTAL]

RESULTADO:
├─ Tool selection accuracy: 85% → 94%
├─ Execution time: Reduced 45%
├─ Cost: Reduced 30%
├─ BUT intelligence: NOT reduced (actually improved)

IMPLEMENTAÇÃO:
├─ RAG-based tool search (find relevant tools)
├─ Hierarchical search levels (basic → advanced)
├─ Dynamic tool set per query
└─ Test locally, iterate on tool selection
```

### 2. Multi-Agent Reasoning with Consensus

```
ADVANCED PATTERN: Disagreement = Deep thinking

┌─────────────────────────────────────────────────────┐
│ SCENARIO: Analyst says SELL, Risk Manager says HOLD │
├─────────────────────────────────────────────────────┤
│                                                     │
│ WHAT HAPPENS:                                       │
│ 1. Orchestrator detects disagreement              │
│ 2. Escalates to "Consensus Loop"                  │
│ 3. Both agents explain their reasoning            │
│ 4. Orchestrator asks challenging questions        │
│ 5. Agents revise positions (or hold)              │
│ 6. Find ground truth or agree on probability      │
│                                                     │
│ OUTCOME: Better decision than either agent alone  │
│                                                     │
│ WHY: Forces deeper reasoning, identifies blind spots
└─────────────────────────────────────────────────────┘
```

### 3. Chain-of-Thought with Explicit Reasoning

```
BEFORE: "Answer is HOLD"

AFTER: "I analyzed this 7 ways:
  1. Technical analysis suggests...
  2. Fundamental analysis contradicts because...
  3. Historical parallel suggests...
  4. Macro factors indicate...
  5. Sentiment analysis shows...
  6. Risk model calculates...
  7. My synthesis: HOLD because #1,#3,#5 are strong
     But monitor because #2,#4 are concerning"

ADVANTAGE:
├─ User understands reasoning
├─ Can challenge specific parts
├─ Can weight differently if they want
├─ Builds trust through transparency
```

// Orchestrator Workflow in n8n

n8n.workflow({
  name: "Minerals Trading - Deep Analysis Agent",
  
  trigger: "Chat webhook",
  
  nodes: [
    // 1. Input Processing
    {
      type: "ChatInput",
      config: {
        systemPrompt: `You are the Chief Analyst orchestrating 8 expert agents...`,
        responseMode: "streaming" // Real-time output
      }
    },
    
    // 2. Complexity Analysis
    {
      type: "LLM",
      model: "claude-3.5-sonnet",
      prompt: `Analyze query complexity. Which agents to deploy? In what sequence?
               Output: JSON with agent plan`
    },
    
    // 3. Parallel Agent Execution
    {
      type: "ParallelFor",
      items: "agents_to_deploy",
      nodes: [
        // Agent Node: News Aggregator
        {
          type: "ExecuteWorkflow",
          workflow: "news_aggregator_agent",
          inputs: { query: "{{ $json.user_query }}" }
        },
        // Agent Node: Fundamental Analyzer
        {
          type: "ExecuteWorkflow",
          workflow: "fundamental_analyzer_agent",
          inputs: { query: "{{ $json.user_query }}" }
        },
        // ... repeat for other agents
      ]
    },
    
    // 4. Synthesis Phase
    {
      type: "LLM",
      model: "gpt-4o",
      prompt: `Synthesize all agent outputs:
               {{ $json.agent_results }}
               
               Create comprehensive analysis with:
               - Root cause (with confidence)
               - Supporting evidence
               - Similar historical precedent
               - Scenarios (bull/base/bear)
               - Recommendation
               - Risk warnings`
    },
    
    // 5. Output Formatting
    {
      type: "MarkdownFormatter",
      config: {
        template: "professional_analysis_template"
      }
    },
    
    // 6. Chat Response
    {
      type: "ChatOutput",
      streaming: true
    }
  ],
  
  memory: {
    type: "conversation_context",
    size: "128k", // Claude 3.5 supports this
    persistence: "this_session"
  }
});
